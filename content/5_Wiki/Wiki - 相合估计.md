## Def 1 弱相合

```ad-definition
title: Definition 1

如果 $\hat{g}(\boldsymbol{X})$ 作为 $g(\theta)$ 的估计量，依概率收敛到 $g(\theta)$，则称其为 $g(\theta)$ 的弱相合估计


```

 [[Wiki - 依概率收敛]]

## Def 2 强相合

```ad-definition
title: Definition 2

若对 $\boldsymbol{X}\in \mathscr{X}$，$\hat{g}(\boldsymbol{X})\xrightarrow{a.s.}g(\theta)$，则称其为 $g(\theta)$ 的强相合估计

```

[[Wiki - 几乎处处收敛]]

## Def 3 矩相合估计

```ad-definition
title: Definition 3

若 $\hat{g}(\boldsymbol{X})$ r 阶平均收敛到 $g(\theta)$， ，则称其为 r 阶相合估计

```
