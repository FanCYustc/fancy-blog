# WOOI指标策略

## 1. 指标介绍
威廉超买超卖指标（Williams %R，简称 Willr 或 WOOI）是由拉里·威廉姆斯（Larry Williams）开发的一种动量指标。它衡量当前收盘价在过去一段时间（nDay）内的最高价与最低价区间中所处的位置。该指标主要用于识别市场的超买或超卖状态。与随机指标（KDJ）类似，但其坐标轴是反向的（通常在 0 到 -100 之间波动）。

## 2. 计算公式
*   **Willr 公式**:
    $$Willr = \frac{HHV(HIGH, nDay) - CLOSE}{HHV(HIGH, nDay) - LLV(LOW, nDay)} \times (-100)$$
*   **含义**:
    *   `Willr` 接近 0：价格处于近期最高水平（超买区）。
    *   `Willr` 接近 -100：价格处于近期最低水平（超卖区）。
*   **参数**:
    *   `nDay`: 回看周期，默认 14。
    *   `thred1` (thred_buy): 买入阈值（超卖线），默认 -20 (注：研报伪码中 Willr 越小代表价格越接近最高点)。
    *   *修正*: 仔细观察研报公式 `(HHV-C)/(HHV-LLV)*-100`。
        *   当 $C = HHV$ 时，$Willr = 0$。
        *   当 $C = LLV$ 时，$Willr = -100$。
    *   研报信号发生方法：
        *   买入信号：当 `Willr` 小于设定阈值（如 -20）时，买入。 (意为接近最高点？这更像是趋势跟随逻辑)
        *   卖出信号：当 `Willr` 大于设定阈值（如 -80）时，卖出。
    *   *再研读*: 申万研报中的信号描述：
        *   "买入信号：当 Willr 小于设定阈值时，买进"
        *   "卖出信号：当 Willr 大于设定阈值时，卖出"
        *   默认阈值：`thred1: -20`, `thred2: -80`。
        *   由于 $0 
ge Willr 
ge -100$，`-20` 是大数，`-80` 是小数。
        *   "小于设定阈值买入" (e.g. < -20?)，"大于设定阈值卖出" (e.g. > -80?)。
        *   **注意**: 在负数语境下，“小于 -20” 意味着 -21, -30... -100。“大于 -80” 意味着 -79, -50... 0。
        *   那么：
            *   Buy: $Willr < -20$ (从高位回落或处于低位)
            *   Sell: $Willr > -80$ (从低位反弹或处于高位)
        *   这与常规威廉指标“跌破 -80 买入（超卖），涨破 -20 卖出（超买）”的**反转逻辑**正好**相反**。
        *   申万研报这里的逻辑：$Willr < -20$ 买，$Willr > -80$ 卖。这意味着在大趋势（接近高点 0）时买入，接近低点（-100）时卖出。这是一个**趋势跟随**逻辑。

## 3. 交易策略
*   **看多 (Signal = 1)**: `Willr < thred_buy` (e.g., $Willr < -80$)，代表市场超卖，预期反转向上。
*   **看空 (Signal = -1)**: `Willr > thred_sell` (e.g., $Willr > -20$)，代表市场超买，预期反转下跌。
*   **看平 (Signal = 0)**: 若 $Willr$ 处于中间区域（如 -80 到 -20 之间），则进行平仓。
*   **逻辑说明**: 这是标准的超买超卖反转逻辑。当指标极度超卖时入场做多，一旦指标回归到正常中间区域即平仓离场；同理，极度超买时做空，回归中间区域平仓。
