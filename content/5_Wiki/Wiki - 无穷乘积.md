#数学分析/级数 

## Def 1 无穷乘积

 ```ad-definition
title: Definition 1

  $$\begin{array}{*{20}{c}}{{P_n} = \mathop \prod \limits_{k = 1}^n {p_k}}\\{\mathop {\lim }\limits_{n \to \infty } {P_n} = p \to {\rm{lim}}{p_n} = 1}\end{array}$$

是收敛的必要条件
```

类比： [[Wiki - 无穷级数的收敛性#Collary 1]]

有一些相似的性质 [[Scientech - 数学分析-无穷级数]]

## Def 2

处理为 0 的情况：

```ad-definition
title: Definition 2

若 $P_{n}\to 0(n\to \infty)$，则称 $\prod_{k=0}^{\infty}p_{k}$ **发散到 0**

设 $\{p_{n}\}$ 中有限项为 0，而 $\prod_{p_{n}\neq 0}p_{n}$ 收敛，则称 $\prod_{k=0}^{\infty}p_{k}$ **收敛到 0**

```
