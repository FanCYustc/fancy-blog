# 二次曲面分类表

根据欧拉 (Euler, 1748) 的研究，三维欧氏空间中的二次曲面在刚体变换下共可分为 15 大类。

## 1. 非退化曲面 (有心或无心)

| 名称 | 标准方程 | 几何特征 |
| :--- | :--- | :--- |
| **椭球面** | $\frac{x^2}{a} + \frac{y^2}{b} + \frac{z^2}{c} = 1$ | 有界，三个对称轴，处处为凸。 ($a\geq b\geq c > 0$) |
| **单叶双曲面** | $\frac{x^2}{a} + \frac{y^2}{b} - \frac{z^2}{c} = 1$ | 无界，连通，单连通，包含两族直线。 |
| **双叶双曲面** | $\frac{x^2}{a} + \frac{y^2}{b} - \frac{z^2}{c} = -1$ | 包含两个不连通的分支。 |
| **椭圆抛物面** | $\frac{x^2}{a} + \frac{y^2}{b} = z$ | 无心曲面，碗状。 |
| **双曲抛物面** | $\frac{x^2}{a} - \frac{y^2}{b} = z$ | 马鞍形，包含两族直线。 |

## 2. 退化曲面 (锥、柱、平面等)

| 名称 | 标准方程 | 备注 |
| :--- | :--- | :--- |
| **椭圆锥面** | $\frac{x^2}{a} + \frac{y^2}{b} - z^2 = 0$ | 顶点 $(0,0,0)$ 是奇点。 |
| **椭圆柱面** | $\frac{x^2}{a} + \frac{y^2}{b} = 1$ | 沿 $z$ 轴方向无限延伸。 |
| **双曲柱面** | $\frac{x^2}{a} - \frac{y^2}{b} = 1$ | - |
| **抛物柱面** | $x^2 = ay$ | - |
| **一对相交平面** | $x^2 - ay^2 = 0$ | $(a>0)$ |
| **一对平行平面** | $x^2 = a$ | $(a>0)$ |
| **一个平面** | $x^2 = 0$ | 重合平面。 |
| **一条直线** | $x^2 + y^2 = 0$ | 相交平面的退化。 |
| **单点** | $x^2 + y^2 + z^2 = 0$ | 椭球面的退化（原点）。 |
| **空集** | $x^2 + y^2 + z^2 = -1$ | 无实数解。 |

## 3. 分类不变量
判断一个二次方程 $F(x,y,z)=0$ 属于哪一类，通常需要计算其二次部分的特征值 $\lambda_1, \lambda_2, \lambda_3$ 以及全矩阵的秩。
- 三个特征值均非零：有心曲面（椭球面、双曲面、锥面）。
- 至少一个特征值为零：无心曲面（抛物面）或柱面/平面。
