## Def 1 效用

```ad-definition
title: Definition 1

消费者从某一特定商品组合的消费中所获得的满足程度，称为效用

```

## Def 2 总效用

```ad-definition
title: Definition  2

总效用是指在一定时期内消费者从消费商品或服务中获得的效用满足总量，记为 TU

```


## Def 3 边际效用

```ad-definition
title: Definition 3

边际效用指在一段时期内消费者从增加一单位商品或服务的消费中所得到的效用增加量，记为 MU

其特点有：
$MU= \frac{\Delta TU}{\Delta Q}\to  \frac{\partial TU}{\partial Q}$

正常情况下 $MU>0$

$\frac{{\partial MU}}{\partial Q}<0$ ：边际效用递减

```
