# 定义

在射影平面 [[Wiki - 射影空间与齐次坐标]] $\mathbb{RP}^2$ 上，**二次曲线 (Quadric / Conic)** 定义为三元二次齐次多项式的零点集：
$$
\mathcal{C} = \{ \mathbf{x} \in \mathbb{RP}^2 \mid \mathbf{x}^T C \mathbf{x} = 0 \}
$$
其中 $C$ 是 $3 \times 3$ 实对称矩阵。

# 射影分类

在 **[[Wiki - 射影变换|射影变换]]** $T_A$ 下，矩阵 $C$ 变换为 $A^T C A$。根据惯性定理，实对称矩阵合同于对角矩阵。二次曲线的分类完全由矩阵 $C$ 的**秩 (Rank)** [[Wiki - 矩阵的秩]]和 **正负惯性指数** 决定。[[Wiki - 惯性定理]]

在 $\mathbb{RP}^2$ 上，共分为 5 类：

| 秩 (Rank) | 标准方程 (特征值符号) | 几何描述 | 欧氏对应 |
| :--- | :--- | :--- | :--- |
| **3** | $x^2 + y^2 - z^2 = 0$ (++-) | **非退化二次曲线** (Oval) | 椭圆, 双曲线, 抛物线 |
| **3** | $x^2 + y^2 + z^2 = 0$ (+++) | **空集** (虚二次曲线) | - |
| **2** | $x^2 - y^2 = 0$ (+-) | **两条相交直线** | 相交线 |
| **2** | $x^2 + y^2 = 0$ (++) | **单点** (两条虚直线交于实点) | 点 |
| **1** | $x^2 = 0$ (+) | **一条重直线** | 重合线 |

# 核心结论

1.  **统一性**: 在射影几何中，椭圆、双曲线、抛物线没有本质区别，它们都属于 **秩为3且特征值不全同号** 的非退化二次曲线类。区别仅在于它们与 **无穷远直线** $l_\infty$ 的相交情况：
    *   **椭圆**: 与 $l_\infty$ 不相交（在复扩充中交于虚点）。
    *   **抛物线**: 与 $l_\infty$ 相切（交于一点）。
    *   **双曲线**: 与 $l_\infty$ 相交于两点（渐近线方向）。
