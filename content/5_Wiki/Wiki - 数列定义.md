[[Book - Mathematical Analysis 1]]

A **sequence** is, formally, a function $a: N \to R$ (or $C$). Usually (i.e. always), we write $a_n$ instead of $a(n)$. Instead of $a$, we usually write it as $(a_n)$, $(a_n)_1^\infty$ or $(a_n)_{n = 1}^\infty$ to indicate it is a sequence.
