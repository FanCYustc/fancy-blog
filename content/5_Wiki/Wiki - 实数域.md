```ad-proposition
$x+y$ is $\{x_{n}+y_{n}\}$ 的等价类代表元；$x\cdot y$ is $\{x_{n}\cdot y_{n}\}$ 的代表元


```

## Def 1 实数的正负

```ad-definition
title: Definition 1

称实数 x 是正的，如果对 x 的代表元 $\{x_{n}\}$，存在 m，$N\in \mathbb{N}$，使得 $\forall j\geq N, x_{j}\geq \frac{1}{m}$[[Wiki - 有序域]]

负的定义同理

一个实数只能为正，0，或负

```


## Pro 3

```ad-proposition
title: Propositon 3

两个正实数的和和积还是正数

```

## Def 2 实数的序

```ad-definition
title: Definition 2

如果 $\exists N \in \mathbb{N},\forall k\geq N, x_{k}\leq y_{k}\to x\leq y$ [[Wiki - 有序域]]

```
