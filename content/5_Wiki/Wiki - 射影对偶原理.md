# 定义

在平面射影几何 $\mathbb{RP}^2$ 中，**点**与**直线**具有对称的地位。这种对称性被称为 **对偶原理 (Duality Principle)**。

## 对偶关系表

| 原概念 | 对偶概念 |
| :--- | :--- |
| 点 $P$ | 直线 $l$ |
| 直线 $l$ | 点 $P$ |
| 点 $P$ 在直线 $l$ 上 (关联) | 直线 $l$ 过点 $P$ (关联) |
| 两点 $P, Q$ 确定一条直线 $P \vee Q$ | 两线 $l, m$ 确定一个交点 $l \wedge m$ |
| 三点共线 | 三线共点 |
| 完全四点形 (Complete Quadrangle) | 完全四边形 (Complete Quadrilateral) |
| 内接于曲线 | 外切于曲线 |

# 代数解释

若点 $P$ 的齐次坐标为 $\mathbf{x} = (x_0 : x_1 : x_2)$，直线 $l$ 的方程为 $u_0 x_0 + u_1 x_1 + u_2 x_2 = 0$。
我们可以将 $(u_0 : u_1 : u_2)$ 视为直线 $l$ 的“线坐标”。
此时方程 $\mathbf{u}^T \mathbf{x} = 0$ 对 $\mathbf{x}$ 和 $\mathbf{u}$ 是完全对称的。

# 对偶原理陈述

**射影平面公理的对偶性**: 射影平面的公理体系对于“点”和“直线”互换后依然成立。
**定理的对偶性**: 如果一个射影几何定理是成立的，那么将该定理中所有的几何元素和关系替换为它们的对偶概念后，所得的新定理（对偶定理）依然成立。

## 经典例子
*   **[[Wiki - 帕普斯定理|帕普斯定理]]**: “点在线上” $\leftrightarrow$ “线过点”。
*   **[[Wiki - 德萨格定理|德萨格定理]]**: 其对偶定理恰好是其逆定理。
*   **[[Wiki - 帕斯卡定理|帕斯卡定理]]**: 内接六边形对边交点共线 $\leftrightarrow$ **[[Wiki - 帕斯卡定理#布里昂雄定理 (Brianchon's Theorem)|布里昂雄定理]]**（外切六边形对角线共点）。
