#数学分析/函数 


对于非周期函数，如何变成周期性[[Wiki - 周期函数的积分]]的

## Def1 周期延拓

对一个定义在 $[ -l, l]$ 上的函数 f，延拓

$$
f\left ( x\right) =\begin{cases}f\left ( x-2nl\right) ;\left ( 2n-1\right) l <x <\left ( 2n+1\right) l\\

\dfrac{f\left ( -l\right) +f\left ( l\right) }{2}; x=\left ( 2n+1\right) l\end{cases}
$$


如果对 $[0, l]$ 上的函数 f，想以 2l 为周期


## Def2 奇延拓：

$$
g\left ( x\right) =\begin{cases}f\left ( x\right) ; 0 <x\leq l\\

0; x=0\\

-f\left ( -x\right) ;-l\leq x <0\end{cases}
$$
## Def3 偶延拓：

$$
g\left ( x\right) =\begin{cases}f\left ( x\right) ; 0\leq x\leq L\\

f\left ( -x\right) ;-L\leq x <0\end{cases}
$$

再化为第一种周期延拓
