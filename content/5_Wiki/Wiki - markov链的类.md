## Def 1 互达

```ad-definition
title: Definition 1

```
对markov链[[Wiki - markov链]]记 $i\to j$，如果存在 n 使得 $P_{ij}^{n}>0$[[Wiki - markov链n步转移概率]]，若 $i\to j,j\to i$ 记为 $i\leftrightarrow j$，称为互达


互达是一种等价关系 [[Wiki - 等价关系]]

## Def 2 类

```ad-definition
title: Definition 2

互达 $\leftrightarrow$ 等价类称为状态空间的类，一个状态空间 S 可以分为至多可数个互不相交的子类。

```


## Def 3

```ad-definition
title: Definition 3

Markov 链是**不可约的**，如果 S 只能分解成一个类

一个类 C 称为**闭的**，如果 markov 链一旦进入类 C 就出不来了


```
