## The 1 Delta 方法

已知 $\sqrt {n}( X_n- \theta ) \overset {d}{\operatorname* { \operatorname* { \to } } }N( 0, \sigma ^2)$, $n\to \infty$, 假设
$g^{\prime}(\theta)\neq0$, 则 $\sqrt n(g(X_n)-g(\theta))\overset d{\operatorname*{\to}}N(0,\sigma^2g^{\prime}(\theta)^2).$
