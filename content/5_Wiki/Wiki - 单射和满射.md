#线性代数/线性变换 
#数学分析/函数 

## Def 1 injective

Function  $T:V\to W$ is called injective is Tu=Tv implies u=v

即不同的元对应不同的像

## Pro 1

$T\in L(V,W)$, T is injective if and only if null T={0}
[[Wiki - 线性映射的像空间和核#Def 1 null space 核]]
很好理解，即 $T(u-v)=0$ 只有唯一零解

[[Wiki - 线性映射]]

## Def  2 surjective

Function $T:V\to W$ is called surjective if range T=W

即像空间 [[Wiki - 线性映射的像空间和核#Def 2 range 像空间]] 覆盖满整个值域空间
