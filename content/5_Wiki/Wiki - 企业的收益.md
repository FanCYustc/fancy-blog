## Def 1 总收益

```ad-definition
title: Definition 1


$$
R=P\cdot Q=P(Q)Q
$$

称为企业的收益函数，P (Q) 为企业面临的需求函数 [[Scientech - 微观经济学-需求、供给和均衡价格]]

```

## Def 2 平均收益

```ad-definition
title: Definition 2


$$
AR= \frac{R}{Q} = P(Q)
$$

称为平均收益

```


## Def 3 边际收益

```ad-definition
title: Definition 3


$$
MR= \frac{dR}{dQ} = \frac{dP}{dQ} Q + P(Q)
$$
称为边际收益

```
