## Def 1 期望效用函数

```ad-definition
title: Definition 1


$$
U(q)=\sum_{i=1}^{s} \alpha_{i}u(q_{i})
$$

称为彩票Q 的**期望效用函数**[[Wiki - 数学期望]]

```

## Def 2 风险厌恶

```ad-definition
title: Definition 1

如果效用函数上凸，则称消费者是**风险厌恶**的
即
$$
U(q)=\sum_{i=1}^{s}\alpha_{i}u(q_{i})<u\left( \sum_{i=1}^{s}\alpha_{i}q_{i} \right)
$$


```

```ad-definition
title: Definition 3

同理下凸就是消费者是**风险喜好**的

```

## Def 3 绝对风险回避系数

```ad-definition
title: Definition 4


$$
r=- \frac{u''}{u'}
$$
称为**绝对风险回避系数**

```
