# 线性规划



## 单纯形法

### 一、快速入门：单纯形法是做什么的？

在你开始深入细节之前，先理解单纯形法的核心思想，这会让你事半功倍。

1.  **目标**：求解线性规划（Linear Programming, LP）问题的最优解。
2.  **与图解法的关系** (教材 P6-P8)：
    *   图解法非常直观，它在二维坐标系上画出可行域（一个凸多边形），然后找到让目标函数最优的那个**顶点**。
    *   但图解法只能处理两个变量的问题。当变量多于两个时，我们就无法画图了。
    *   **单纯形法**本质上就是图解法的代数版本。它的核心思想是：**从可行域的一个顶点出发，沿着边移动到另一个更好的相邻顶点，一步步迭代，直到找到最优的顶点为止。**

> **一句话总结**：单纯形法是一个高效的、标准化的迭代算法，通过在可行域的顶点之间“跳跃”，最终找到多变量线性规划问题的最优解。

---

### 二、核心知识点梳理 (单纯形法的“语法”)

要掌握单纯形法，你需要先熟悉它的一套“语言”和规则。

#### 1. 线性规划的标准形式 (Standard Form) (教材 P4)

算法的运行需要一个标准化的输入。单纯形法要求的标准形式有以下几个特点：

$$
\begin{align}
\max & \sum c_{i}x_{i} \\
s.t. & Ax = b\geq 0  \\
& x\geq 0
\end{align}
$$
[[Scientech - 凸优化-凸优化和对偶]]

*   **目标函数**：求最大值 (Maximization)。
*   **约束条件**：所有约束都是等式 (Equality)。
*   **右端项 (RHS)**：所有约束等式右边的常数 `b` 均为非负 (`b ≥ 0`)。
*   **变量**：所有决策变量均为非负 (`x ≥ 0`)。

#### 2. 如何化为标准形式？(教材 P4-P5)

任何线性规划问题都可以通过以下变换化为标准形式，这是求解的第一步，务必掌握：

*   **目标函数极小化**：`min z` 等价于 `max (-z)`。将目标函数整体乘以-1 即可。
*   **约束条件为不等式**：
    *   `≤` 型约束：在左边加上一个**松弛变量 (Slack Variable)**，使其变为等式。例如 `x1 + x2 ≤ 5` 变为 `x1 + x2 + x3 = 5`，其中 `x3 ≥ 0`。松弛变量代表资源的“剩余量”。
    *   `≥` 型约束：从左边减去一个**剩余变量 (Surplus Variable)**。例如 `x1 + x2 ≥ 5` 变为 `x1 + x2 - x4 = 5`，其中 `x4 ≥ 0`。剩余变量代表“超出”的部分。
*   **右端项为负**：将整个约束等式两边同乘以 `-1`。
*   **无约束变量**：如果变量 `x` 可以取任何实数（无非负约束），则令 `x = x' - x''`，其中 `x', x'' ≥ 0`，并代入模型中。

#### 3. 单纯形法中的重要概念 (教材 P9)

这些概念是理解算法每一步操作背后意义的关键。

*   **基 (Basis)**：从约束方程系数矩阵 A 中找到的 `m` 个线性无关的列向量组成的满秩矩阵。简单来说，它构成了一个坐标系。
*   **基变量 (Basic Variables)**：与“基”中的列向量对应的变量。在单纯形表中，它们是每一行开头的变量。
*   **非基变量 (Non-basic Variables)**：除了基变量以外的其他变量。
*   **基解 (Basic Solution)**：令所有**非基变量=0**，求解出的唯一一组解。
*   **基可行解 (Basic Feasible Solution, BFS)**：所有变量值都非负的**基解**。**这在几何上就对应了可行域的一个顶点！** 单纯形法的每一步迭代，都是从一个基可行解移动到另一个基可行解。

### 三、难点攻克与计算步骤详解

这是整个方法的核心，也是最容易出错的地方。我们将结合单纯形表（Simplex Tableau）来讲解。

#### 难点 1：如何启动算法？—— 寻找第一个基可行解

*   **简单情况**：如果所有约束都是 `≤` 型，那么加入的松弛变量恰好构成一个单位矩阵。我们可以让这些松弛变量作为**初始基变量**，所有原始决策变量作为非基变量（令它们为 0），这样就轻松得到了第一个基可行解。
*   **复杂情况** (教材 P30-P32)：当模型中存在 `≥` 或 `=` 约束时，无法直接找到单位矩阵作为初始的基。这时需要引入**人工变量 (Artificial Variables)**。

    *   **大 M 法 (Big M Method)**：
        1.  在 `≥` 或 `=` 约束的方程左侧加入人工变量，使它们与松弛变量一起构成一个初始的基（单位矩阵）。
        2.  为了在计算中尽快将这些“假”的变量赶出基，我们在目标函数中给它们一个巨大的**惩罚**。对于 `max` 问题，就是在目标函数中减去 `M * (人工变量)`，其中 `M` 是一个非常大的正数。
        3.  之后正常进行单纯形法迭代。如果最终解中**人工变量不为 0**，说明原问题**无可行解**。

    *   **两阶段法 (Two-Phase Method)**：
        1.  **第一阶段**：构造一个新的目标函数，目标是**最小化所有人工变量之和**。对此问题进行求解。
            *   若最优解的目标函数值 **不为 0**，说明人工变量无法被全部赶出基，原问题**无可行解**。
            *   若最优解的目标函数值 **为 0**，说明找到了原问题的一个基可行解。进入第二阶段。
        2.  **第二阶段**：在第一阶段得到的最终单纯形表中，去掉人工变量，恢复原来的目标函数，并以此为起点继续求解。

> **提示**：手算时，大 M 法比较直观。计算机求解常用两阶段法，以避免数值计算问题。

#### 难点 2：单纯形法的迭代过程 (教材 P26-P27)

假设我们已经有了一个初始的单纯形表，迭代步骤如下：

**第 1 步：检验当前解是否最优**
*   计算**检验数 (Test Number)**行，通常记为 `c_j - z_j` 或 `σ_j`。对于最大化问题：
    *   **最优标志**：如果所有检验数都 `≤ 0`，那么当前解就是最优解，计算结束。
    *   **非最优**：如果存在大于 0 的检验数，说明当前解还有改进空间，需要继续迭代。

**第 2 步：寻找改进方向 (换入与换出)**
*   **确定换入变量 (Entering Variable)**：选择**最大正检验数**对应的那个**非基变量**，作为换入变量。这个变量进入基后，能最快地提升目标函数值。它所在的那一列被称为**主元列 (Pivot Column)**。
*   **确定换出变量 (Leaving Variable)**：用资源值 `b` 列的每个元素，分别除以主元列对应的正数元素，计算**比值 `θ`**。选择**最小的非负比值** `θ` 对应的那一行的**基变量**，作为换出变量。这一步（最小比值检验）是为了保证下一次迭代的解仍然是可行的（即所有变量非负）。该行被称为**主元行 (Pivot Row)**。

**第 3 步：更新解 (矩阵变换)**
*   位于主元行和主元列交叉点的元素被称为**主元 (Pivot Element)**。
*   通过**行变换（高斯消元法）**，将主元变为 1，并将主元列的其他所有元素变为 0。
*   这样，我们就完成了一次迭代，得到了一个新的单纯形表（代表一个新的顶点）。

**第 4 步：重复**
*   回到第 1 步，对新的单纯形表进行最优性检验，循环往复，直到找到最优解。

#### 难点 3：如何解读最终的单纯形表？(教材 P17, P33)

计算结束后，最终的表会告诉你解的四种可能结局：

1.  **唯一最优解 (Unique Optimal Solution)**：所有非基变量的检验数都严格小于 0。
2.  **无穷多最优解 (Multiple Optimal Solutions)**：在最优表中，至少有一个非基变量的检验数为 0。这意味着可以将这个变量换入基中，得到一个目标函数值相同但变量取值不同的新解。
3.  **无界解 (Unbounded Solution)**：在某次迭代中，确定了换入变量（检验数>0），但在计算比值 `θ` 时，发现其主元列的所有元素都 `≤ 0`。这表示换入变量可以无限增大，而目标函数值也随之无限增大。
4.  **无可行解 (No Feasible Solution)**：使用大 M 法或两阶段法，最终的最优表中仍含有大于 0 的人工变量。

## 对偶单纯形法

### 一、为什么需要对偶单纯形法？它和“正牌”的单纯形法有什么不同？

要理解对偶单纯形法，最好的方式是和我们已经熟悉的单纯形法（为了区分，我们称之为**原始单纯形法 Primal Simplex Method**）进行对比。

*   **原始单纯形法**：
    *   **出发点**：从一个**可行**但**非最优**的解（一个基可行解）开始。
    *   **迭代过程**：在每一步都**保持可行性**（`b` 列的值始终 ≥ 0），通过迭代逐步**追求最优性**（让所有检验数 `c_j - z_j ≤ 0`）。
    *   **好比**：我们在可行域的一个顶点上，每一步都跳到旁边一个更好的顶点，直到山顶。

*   **对偶单纯形法**：
    *   **出发点**：从一个**不可行**但**“超最优”**的解开始。这里的“超最优”指的是解已经满足了最优性检验（所有检验数 `c_j - z_j ≤ 0`），但却不满足可行性（`b` 列中出现了负值）。
    *   **迭代过程**：在每一步都**保持最优性检验**（检验数行始终 ≤ 0），通过迭代逐步**追求可行性**（想办法消除 `b` 列的负值，让它们都 ≥ 0）。
    *   **好比**：我们空降到了一个比“山顶”还高的地方（但这地方是虚构的、不可行的），然后一步步下降，直到落到可行域的最高点上。

> **核心思想** (教材 P50)：对偶单纯形法本质上是在**原问题的单纯形表**上，执行**对偶问题的原始单纯形法**步骤。它是一个在迭代中始终保持**对偶可行**（即原问题检验数满足最优性条件），并逐步趋向**原始可行**的算法。

---

### 二、算法步骤详解 (The "How-To")

对偶单纯形法的迭代规则与原始单纯形法刚好是“反”过来的。我们来看它的“三部曲”。

**前提条件**：单纯形表的检验数行 (`c_j - z_j`) 必须全部 `≤ 0`。（这是启动对偶单纯形法的基础）

#### 第 1 步：确定换出变量 (确定主元行)

*   **规则**：选取 `b` 列中**最负的元素**（或者说，负得绝对值最大的元素）。它所在的行就是**主元行**，对应的基变量就是**换出变量**。
*   **为什么**：`b` 列的负值意味着该约束不被满足，我们优先处理这个“最不可行”的约束。
    (对应教材 P51, 规则 1)

#### 第 2 步：确定换入变量 (确定主元列)

*   **规则**：用**检验数行** (`c_j - z_j`) 的每个元素，分别去除以**主元行**的**对应负数元素**，然后对这些比值的**绝对值**取最小值。这个最小绝对值比值所在的列，就是**主元列**，对应的非基变量就是**换入变量**。
    *   数学公式 (教材 P51, 公式 2.26): `θ = min { | (c_j - z_j) / a_rj | }`，其中 `a_rj < 0` (主元行的元素必须是负数)。
*   **为什么**：这一步是为了保证在下一次迭代中，检验数行依然满足 `≤ 0` 的条件，即保持“对偶可行性”。

#### 第 3 步：迭代更新 (高斯消元)

*   和原始单纯形法完全一样。找到主元（主元行和主元列的交叉点），通过行变换将其变为 1，并将该列的其他元素变为 0。

#### 终止条件

1.  **找到最优解**：当 `b` 列的所有元素都 `≥ 0` 时，算法终止。此时的解既满足原始可行性，又满足最优性检验，因此就是原问题的最优解。
2.  **原问题无解**：如果在某一步，确定了主元行（`b_r < 0`），但该行**所有元素 `a_rj` 都 `≥ 0`**，则算法终止。这说明原问题**无可行解**。 (教材 P52, 顶部有提及)

### 三、教材实例解析 (例 4, P52)

让我们跟着你的教材，把这个过程走一遍，这会让你彻底明白。

**问题**：求解 `min w = 15y1 + 24y2 + 5y3` 的 LP 问题，约束条件为 `≥` 型。
在化为标准型并构建单纯形表后，我们得到的初始表为 **表 2-8**。

**初始状态 (表 2-8)**：
*   **检验数行**：`(-15, -24, -5, 0, 0)`，所有值都 `≤ 0`。**满足对偶单纯形法的启动条件**。
*   **b 列**：`(-2, -1)`。存在负值。**说明当前解不可行**。

**第一次迭代**：

1.  **确定主元行**：`b` 列中最负的元素是 `-2` (在 `y4` 这一行)。所以，**`y4` 是换出变量**，该行为主元行。
2.  **确定主元列**：
    *   主元行 `y4` 的元素为 `(0, [-6], -1, 1, 0)`。其中负数元素为 `-6` 和 `-1`。
    *   计算比值：
        *   `y2` 列: `| (-24) / (-6) | = 4`
        *   `y3` 列: `| (-5) / (-1) | = 5`
    *   取最小绝对值比值 `4`。所以，**`y2` 是换入变量**，该列为主元列。
    *   主元是 `-6`。
3.  **行变换**：经过高斯消元，得到中间的那个表。

**第二次迭代**：

1.  **确定主元行**：新表的 `b` 列为 `(1/3, -1/3)`。唯一的负值是 `-1/3` (在 `y5` 这一行)。所以，**`y5` 是换出变量**。
2.  **确定主元列**：
    *   主元行 `y5` 的元素为 `(-5, 0, [-2/3], -1/3, 1)`。其中负数元素为 `-2/3` 和 `-1/3`。
    *   计算比值：
        *   `y3` 列: `| (-1) / (-2/3) | = 3/2`
        *   `y4` 列: `| (-4) / (-1/3) | = 12`
    *   取最小绝对值比值 `3/2`。所以，**`y3` 是换入变量**。
    *   主元是 `-2/3`。
3.  **行变换**：再次进行高斯消元，得到表 2-8 最后的那个表。

**终止**：
*   观察最终的单纯形表，`b` 列为 `(1/4, 1/2)`，所有值均 `≥ 0`。
*   同时，检验数行 `( -15/2, 0, 0, -7/2, -3/2 )` 仍然 `≤ 0`。
*   **结论**：算法终止，找到最优解。从表中可以读出最优解。

### 四、对偶单纯形法的应用场景 (The "When")

你可能会问，既然原始单纯形法能解决问题，为什么还要学这个？对偶单纯形法在以下场景中极其高效：

1.  **灵敏度分析 (Sensitivity Analysis)**：这是最重要的应用！当你求出一个最优解后，如果：
    *   **增加了一个新的约束条件**：这个新约束可能使得当前最优解变得不可行（代入后不满足），但检验数的最优性 `(c_j-z_j ≤ 0)` 不变。这时，你只需要在最终单纯形表中加上这个新约束对应的行，然后用**对偶单纯形法**进行几步迭代即可，**无需从头计算**！
    *   **改变了资源量 `b_i`**：如果 `b_i` 的变化导致 `b` 列出现负值，同样可以用对偶单纯形法快速修正。

2.  **整数规划**：在一些整数规划的算法（如割平面法）中，会不断地向模型中添加新的约束（割平面），这时使用对偶单纯形法来求解就非常自然和高效。

### 总结：原始 vs. 对偶

| 特性 | **原始单纯形法** | **对偶单纯形法** |
| :--- | :--- | :--- |
| **出发点** | 基可行解 (b ≥ 0) | 对偶可行解 (c_j-z_j ≤ 0) |
| **迭代过程** | 保持可行，追求最优 | 保持最优性，追求可行 |
| **换入变量** | 选**最大正**检验数 | 选**最小绝对值比值** |
| **换出变量** | 选**最小非负比值 `θ`** | 选 `b` 列中**最负**的元素 |
| **最优条件** | 所有 `c_j - z_j ≤ 0` | 所有 `b_i ≥ 0` |

## 灵敏度分析

好的，我们来系统地总结一下线性规划中非常重要的一个环节——**灵敏度分析 (Sensitivity Analysis)**。这部分内容在你教材的**第二章第五节 (P53)** 有详细讲解。

### 一、灵敏度分析是什么？为什么它如此重要？

在我们解决一个线性规划问题时，模型中的所有参数（如利润系数 `c_j`，资源限量 `b_i`，消耗系数 `a_ij`）都被假定为是**确定不变的**。但在现实世界中，这些数值往往是**估计值或预测值**，它们随时可能发生变化：
*   产品售价或成本变了 (`c_j` 变化)
*   可用的原材料数量或工时变了 (`b_i` 变化)
*   生产工艺改进，资源消耗率变了 (`a_ij` 变化)
*   公司考虑是否要开发一个新产品 (增加新变量)
*   生产中增加了一条新的限制 (增加新约束)

**灵敏度分析**就是要回答这样一个问题：“**当模型的某些参数发生变化时，我们辛辛苦苦求出来的最优解会受到什么影响？它还是最优的吗？如果不是，我们该怎么办？**”

> **核心价值** (教材 P53): 灵敏度分析的精髓在于，我们**不需要**每次都从头开始重新运行整个单纯形法。而是**在最终的最优单纯形表的基础上**，通过少量的计算来快速分析变化带来的影响，并找到新的最优解。这极大地提高了决策效率。

---

### 二、灵敏度分析的通用框架

在你教材 P53 中提到了一个通用步骤，我们可以把它总结为：

1.  **更新**：根据参数的变化，计算这些变化对最终最优单纯形表中数值的影响。
2.  **检验可行性**：检查 `b` 列的值是否仍然**非负** (`b' ≥ 0`)。这被称为**原始可行性 (Primal Feasibility)**。
3.  **检验最优性**：检查检验数行的值是否仍然满足最优条件 (`c_j' - z_j' ≤ 0` for max problem)。这被称为**对偶可行性 (Dual Feasibility)**。
4.  **决策/迭代**：
    *   如果**可行性**和**最优性**都满足，那么最优基不变，只是解的具体数值和目标函数值可能更新。
    *   如果**最优性满足**但**可行性被破坏**（`b` 列出现负值），使用**对偶单纯形法**继续迭代。
    *   如果**可行性满足**但**最优性被破坏**（检验数行出现正值），使用**原始单纯形法**继续迭代。
    *   如果两者都被破坏，通常需要引入人工变量，重新求解。

### 三、分情况讨论：各种参数变化分析方法

#### 情况一：目标函数系数 `c_j` 的变化 (教材 P54)

这种变化**只影响最优性**，不影响可行性（因为 `b` 列和约束系数矩阵没变）。

*   **`c_j` 是一个非基变量的系数**：
    *   **影响**：只影响其自身的检验数 `c_j - z_j`。
    *   **方法**：重新计算这个检验数。如果结果仍然 `≤ 0`，则最优解**完全不变**。如果 `> 0`，则将该列作为主元列，用**原始单纯形法**继续迭代。
*   **`c_j` 是一个基变量的系数**：
    *   **影响**：会影响到**整个检验数行**，因为 `z_j` 的计算依赖于基变量的成本 `C_B`。
    *   **方法**：重新计算所有非基变量的检验数。如果它们仍然都 `≤ 0`，则**最优基不变**，但最优解的目标函数值会改变。如果出现正检验数，则用**原始单纯形法**迭代。
*   **求解允许变化范围** (教材 P55, 例 5 (2))：
    *   这是非常常见的考点。方法是：设 `c_j` 的变化量为 `Δc_j`，将它代入检验数表达式中，建立不等式 `(c_j' - z_j') ≤ 0`，然后解出 `Δc_j` 的范围。在这个范围内，当前的最优基保持不变。

#### 情况二：约束右端项 `b_i` 的变化 (教材 P55)

这种变化**只影响可行性**，不影响最优性（因为检验数行的计算与 `b_i` 无关）。

*   **影响**：会改变单纯形表中 `b` 列的值。
*   **方法**：
    1.  找到最终单纯形表中，初始松弛/人工变量所在的列，这些列构成了**最优基的逆矩阵 `B⁻¹`**。
    2.  计算新的 `b` 列：`b_new = B⁻¹ * b_original_new`。或者更简单地，`b_new = b_current_optimal + B⁻¹ * Δb`。(`Δb` 是 `b_i` 的变化向量)。
    3.  检查 `b_new` 的所有元素：
        *   如果全部 `≥ 0`，则**最优基不变**，只是解的取值和目标函数值改变了。
        *   如果出现负值，说明当前解不再可行。此时检验数行仍然是最优的，这正是**对偶单纯形法**大显身手的时刻！从 `b_new` 列最负的元素开始，用对偶单纯形法迭代求解。
*   **求解允许变化范围** (教材 P56, 例 6 (2))：
    *   方法是：建立不等式组 `b_new ≥ 0`，即 `b_current_optimal + B⁻¹ * Δb ≥ 0`，然后解出 `Δb_i` 的范围。这个范围通常被称为**影子价格 (Shadow Price) 的有效范围**。

#### 情况三：增加一个新变量 `x_k` (一个新产品) (教材 P56)

*   **影响**：可能影响最优性。
*   **方法**：
    1.  利用最终单纯形表中的对偶信息（影子价格 `y = C_B * B⁻¹`），计算这个新变量的检验数：`c_k - z_k = c_k - y * P_k` (`P_k` 是新变量的系数列)。
    2.  检查检验数 `c_k - z_k` ：
        *   如果 `≤ 0`，说明引入这个新变量（新产品）不划算，**最优解不变**。
        *   如果 `> 0`，说明值得引入。需要先计算它在当前基下的表示 `P'_k = B⁻¹ * P_k`，然后将这一列加入到最优单纯形表中，用**原始单纯形法**继续迭代。
    (参考教材 P57, 例 7)

#### 情况四：增加一个新约束条件 (教材 P59)

*   **影响**：可能影响可行性。
*   **方法**：
    1.  将当前的最优解代入新的约束条件中进行检验。
        *   如果满足新约束，那么这个约束是多余的，对最优解**没有影响**。
        *   如果不满足新约束，说明当前最优解变得不可行了。
    2.  将这个新约束（已加入松弛/剩余变量并化为等式）添加到最优单纯形表的底部。
    3.  由于新加的行会破坏原有基变量列的单位矩阵结构，需要通过**行变换**来恢复。
    4.  恢复后，新约束行对应的 `b` 值通常会是负数。此时，检验数行仍然满足最优性，我们再次使用**对偶单纯形法**来找到新的最优解。
    (参考教材 P59, 例 9)

### 四、总结与快速记忆

| 参数变化类型 | 主要影响 | 检验方法 | 后续处理方法 |
| :--- | :--- | :--- | :--- |
| **目标系数 `c_j`** | **最优性** | 检查 `c_j - z_j` 是否 `≤ 0` | 若否则用**原始单纯形法** |
| **右端项 `b_i`** | **可行性** | 检查 `b` 列是否 `≥ 0` | 若否则用**对偶单纯形法** |
| **增加新变量 `x_k`** | **最优性** | 计算新变量的检验数是否 `≤ 0` | 若否则用**原始单纯形法** |
| **增加新约束** | **可行性** | 检查当前解是否满足新约束 | 若不满足，添加约束后用**对偶单纯形法** |

## 运输问题

### 一、核心思想：为什么不用标准单纯形法？

*   **结构特殊**：运输问题的约束系数矩阵非常稀疏，且只有 0 和 1（教材 P73）。直接套用标准单纯形法会产生大量退化解，计算效率低下。
*   **表上作业法**：利用运输问题的特殊结构，所有计算都可以直接在一个称为“运输表”的表格中完成，非常直观，避免了复杂的矩阵运算。

**整个求解过程就像一个三步走的循环：**

1.  **找初始方案**：快速找到一个初始可行解（Initial Basic Feasible Solution）。
2.  **判别最优**：检验当前方案是不是最优的。如果是，则停止；如果不是，则进入第三步。
3.  **调整改进**：对当前方案进行调整，得到一个更好的新方案，然后返回第二步。

---

### 二、步骤一：寻找初始基可行解 (IBFS)

这是算法的起点。目标是找到 `m+n-1` 个基变量（即填有数字的格子），且这些格子不能构成闭合回路。教材介绍了两种主要方法：

#### 1. 最小元素法 (Minimum Cost Method) (教材 P75)

*   **思想**：非常直观的贪心算法——优先满足运价最低的路线。
*   **步骤**：
    1.  在整个运价表中，找到成本 `c_ij` 最小的那个格子。
    2.  在这个格子里，尽可能多地分配运量，取其所在行的**供给量**和所在列的**需求量**中的**最小值**。
    3.  划掉已被满足的行或列（如果供需同时满足，可任意划掉一个，另一个的供需量变为 0）。
    4.  在剩下未被划掉的格子中，重复以上步骤，直到所有供需都满足为止。
*   **优点**：简单，容易理解。
*   **缺点**：只考虑局部最优，得到的初始解质量可能不高，导致后续调整次数较多。

#### 2. 沃格尔法 (Vogel's Approximation Method, VAM) (教材 P76)

*   **思想**：一个更“聪明”的贪心算法。它不仅考虑最小成本，还考虑了**“次小成本”**，计算不选择最小成本路线的**“机会成本”或“罚数”**，优先处理罚数最大的行或列。
*   **步骤**：
    1.  计算每一行和每一列的**罚数 (Penalty)**：即该行/列中，最小的两个运价之差。
    2.  找到**罚数最大**的行或列。
    3.  在该行/列中，找到**运价最小**的格子，并尽可能多地分配运量（取该行列供需的最小值）。
    4.  划掉被满足的行或列。
    5.  在剩余的表中，重新计算罚数，并重复以上步骤，直到所有供需满足。
*   **优点**：通常能得到一个质量很高的初始解，非常接近甚至就是最优解，大大减少后续的迭代次数。
*   **缺点**：计算过程比最小元素法稍复杂。

> **学习建议**：**务必掌握沃格尔法**，它是寻找初始解的最佳手算方法。

---

### 三、步骤二：检验当前解是否最优

找到了初始解后，我们需要一个方法来判断它是不是最优的。这相当于在标准单纯形法中计算检验数。这里也有两种方法：

#### 1. 闭回路法 (Stepping-Stone Method) (教材 P78)

*   **思想**：对每一个**非基变量（空格子）**，计算如果向这个格子里调入一个单位的运量，总成本会发生什么变化。
*   **步骤**：
    1.  选择一个空格子作为起点。
    2.  从这个空格子出发，寻找一条**唯一的闭合回路**。这条回路的特点是，除了起点外，**所有的转角点都必须是填有数字的格子（基变量）**。
    3.  从起点开始，给路径上的格子依次标上 `+`, `-`, `+`, `-`...
    4.  计算这个空格子的**检验数**：将标 `+` 的格子的运价相加，减去标 `-` 的格子的运价。
    5.  对所有空格子重复此操作。
*   **最优判据**：如果所有空格子的检验数都 `≥ 0`，则当前解为最优解。如果存在负检验数，则解还有改进空间。
*   **缺点**：需要为每一个空格子都寻找一条闭回路，当问题规模大时非常繁琐。

#### 2. 对偶变量法 (位势法, MODI Method) (教材 P79)

*   **思想**：这是闭回路法的一个巨大改进，它利用了线性规划的对偶理论，避免了反复画闭回路。它是**目前手算最优的检验方法**。
*   **步骤**：
    1.  为每一行引入一个对偶变量 `u_i`，为每一列引入一个对偶变量 `v_j`。
    2.  对于所有**填有数字的格子（基变量）**，令其满足方程 `u_i + v_j = c_ij`。
    3.  这是一个含有 `m+n` 个变量和 `m+n-1` 个方程的方程组。任意令其中一个变量为 0（通常令 `u_1 = 0`），即可解出所有的 `u_i` 和 `v_j`。
    4.  对于所有**空格子（非基变量）**，计算其**检验数 `σ_ij = c_ij - (u_i + v_j)`**。
*   **最优判据**：
    *   如果所有的 `σ_ij ≥ 0`，则当前解为最优解。
    *   如果存在 `σ_ij < 0`，则当前解可以继续优化。

---

### 四、步骤三：解的改进与迭代

如果检验发现当前解不是最优的（即存在负检验数），我们需要进行调整。

1.  **确定调整方向**：
    *   在所有检验数为负的空格子中，选择**检验数最小（即负得最厉害）**的那个格子。这个格子就是“换入变量”。
2.  **确定调整量**：
    *   为这个换入的空格子寻找它的**闭合回路**（和闭回路法一样）。
    *   在回路上，将换入的空格子标为 `+`，然后交替标 `-`, `+`, `-`...
    *   找到所有标 `-` 的格子中的**最小运量**，这个值就是本次的**调整量 `θ`**。
3.  **进行调整**：
    *   将所有标 `+` 的格子的运量加上 `θ`。
    *   将所有标 `-` 的格子的运量减去 `θ`。
    *   调整后，原路径上运量最小的那个标 `-` 的格子，其运量会变为 0，成为新的空格子（换出变量）。而换入的空格子运量变为 `θ`。
4.  **循环**：得到新的可行解后，返回**步骤二**，重新计算位势 `u_i, v_j` 并检验新的空格子，循环往复，直到所有检验数都非负为止。

### 五、特殊情况处理 (难点与考点)

#### 1. 产销不平衡问题 (Unbalanced Problem) (教材 P84)

*   **总供给 > 总需求**：增加一个**虚拟销地**，其需求量等于总供给与总需求的差额。从任何产地到该虚拟销地的运价都设为**0**。
*   **总需求 > 总供给**：增加一个**虚拟产地**，其供给量等于总需求与总供给的差额。从该虚拟产地到任何销地的运价都设为**0**。
*   处理后，问题就变成了产销平衡问题，可以正常求解。

#### 2. 退化问题 (Degeneracy) (教材 P84)

*   **什么是退化**：当运输表中的基变量（填数格）个数**少于 `m+n-1`** 时，就发生了退化。
*   **为什么是问题**：退化会导致无法唯一解出所有的位势 `u_i, v_j`，或者在找闭回路时找不到足够的转角点，使得检验和调整无法进行。
*   **解决方法**：在某个适当的**空格子**中填上一个运量为 **0** 的数，将其视为一个基变量，凑够 `m+n-1` 个基变量。选择这个格子的位置有讲究，必须保证它与其它填数格**不构成闭合回路**。

希望这份总结能帮助你清晰地掌握运输问题的求解脉络。核心就是要熟练掌握“**沃格尔法找初始解 + 位势法检验和调整**”这一套组合拳。

## 目标规划

### 一、目标规划的核心思想：从“最优化”到“满意化”

首先，我们要理解目标规划与线性规划在哲学思想上的根本不同：

*   **线性规划 (LP)**：追求**单一目标**的**最优化**。比如，利润最大化 *或* 成本最小化。它要求所有约束都必须严格满足，否则就是不可行。这是一种“刚性”的模型。
*   **目标规划 (GP)**：追求**多个目标**的**满意化**。它承认现实中多个目标（如高利润、低成本、高市场份额、低加班率）可能无法同时达到最优。因此，它的目标是找到一个**尽可能接近**预设目标值的“满意解”。它允许某些目标在一定程度上偏离，这是一种“柔性”的模型。

> **一句话总结**：线性规划找的是“最好的解”，而目标规划找的是“最令人满意的折中解”。

---

### 二、目标规划的“语法”：三大核心要素

要构建一个目标规划模型，你需要掌握它的三个独特构成部分（教材 P96-P97）：

#### 1. 偏差变量 (Deviational Variables) `d⁻` 和 `d⁺`

这是目标规划的灵魂。对于每一个目标，我们引入一对偏差变量：
*   **负偏差变量 `d⁻`**：表示**未能达到**目标值的部分 (Underachievement)。
*   **正偏差变量 `d⁺`**：表示**超过**目标值的部分 (Overachievement)。

例如，设利润目标为 48 万元，实际利润为 `6x₁ + 8x₂`。我们可以写出目标约束：
`6x₁ + 8x₂ + d₁⁻ - d₁⁺ = 48`

*   如果实际利润是 40 万，则 `d₁⁻=8, d₁⁺=0` (差了 8 万)。
*   如果实际利润是 50 万，则 `d₁⁻=0, d₁⁺=2` (超了 2 万)。
*   如果恰好是 48 万，则 `d₁⁻=0, d₁⁺=0` (完美达成)。

**关键性质**：`d⁻ ≥ 0`, `d⁺ ≥ 0`，并且在一个最优解中，必然有 `d⁻ * d⁺ = 0` (不可能同时既未达到又超过目标)。

#### 2. 优先因子 (Priority Factors) `Pₖ`

现实中的多个目标通常有主次之分。目标规划用**优先因子 `Pₖ`** 来表示目标的**绝对优先级**。
*   `P₁` 代表最高优先级，`P₂` 代表次高优先级，以此类推。
*   **规则**：`Pₖ` 的优先级**远远高于** `Pₖ₊₁` (`Pₖ >> Pₖ₊₁`)。这意味着，**只有在完全满足了 `Pₖ` 级别目标的前提下，系统才会开始考虑优化 `Pₖ₊₁` 级别的目标**。低优先级目标的实现，不能以牺牲高优先级目标为代价。

#### 3. 目标函数 (Achievement Function)

目标规划的目标函数总是**最小化**不希望出现的**偏差变量**。它由优先因子 `Pₖ` 和相应的偏差变量构成。
`min z = P₁(...偏差变量...) + P₂(...偏差变量...) + P₃(...偏差变量...) + ...`

具体最小化哪个偏差变量，取决于决策者的意图：
*   **恰好达到目标** (e.g., 生产 100 件)：`min (d⁻ + d⁺)`
*   **不低于目标** (e.g., 利润不低于 100 万)：`min d⁻`
*   **不超过目标** (e.g., 成本不超过 100 万)：`min d⁺`

---

### 三、目标规划的数学模型与求解方法

#### 1. 目标规划的标准形式

一个典型的目标规划模型如下 (教材 P97)：
`min z = P₁(w₁₁d₁⁻ + w₁₁'d₁⁺ + ...) + P₂(w₂₂d₂⁻ + w₂₂'d₂⁺ + ...) + ...`
s.t.
*   **目标约束 (Goal Constraints)**：`fᵢ(X) + dᵢ⁻ - dᵢ⁺ = gᵢ` (for i = 1, 2, ..., m)
*   **绝对约束 (System Constraints)**：`hⱼ(X) ≤ (or ≥, =) bⱼ` (for j = 1, 2, ..., k)
*   **非负约束**：`X, dᵢ⁻, dᵢ⁺ ≥ 0`

这里的 `w` 是**权重系数**，用于处理**同一优先级**内不同目标相对重要性的情况。

#### 2. 求解方法

目标规划本质上是线性规划的一种变体，因此可以用单纯形法来求解。主要有两种方法：

##### (1) 序贯单纯形法 (Sequential Simplex Method)

这是最符合目标规划逻辑的解法，但计算上可能繁琐。
*   **思想**：严格按照优先级顺序，一个一个地优化目标。
*   **步骤**：
    1.  **第一步**：只考虑 `P₁` 级别的目标，构造目标函数 `min z₁ = ...P₁相关的偏差...`，在满足所有绝对约束的条件下求解这个 LP 问题。
    2.  **第二步**：将上一步求得的最优目标值 `z₁*` 作为一个**新的绝对约束**加入模型中。然后，再考虑 `P₂` 级别的目标，构造 `min z₂ = ...P₂相关的偏差...` 进行求解。
    3.  **依此类推**：不断将上一级已实现的最优目标值作为约束，来优化下一级的目标，直到所有优先级都处理完毕。

##### (2) 修正单纯形法 (Modified Simplex Method / Simplex Method for GP) (教材 P100)

这是更常用、更高效的解法。它通过改造单纯形表，一次性处理所有优先级。
*   **核心改造**：单纯形表的检验数行不再是一行，而是**多行**，**每一行对应一个优先级 `Pₖ`**。
    *   例如，如果有 3 个优先级，检验数区域就会有 3 行，分别代表 `P₁`、`P₂` 和 `P₃` 的系数。
*   **迭代步骤 (以最小化为例)**：
    1.  **确定换入变量**：
        *   **首先看 `P₁` 检验数行**。如果该行存在**负数**，则在这些负数中选择**绝对值最大**的那个，其对应的列为**主元列**。**此时完全不考虑 `P₂`, `P₃`... 等低优先级的检验数。**
        *   **如果 `P₁` 检验数行全部非负**，说明 `P₁` 级别的目标已经最优。这时再**看 `P₂` 检验数行**，在其中找绝对值最大的负数来确定主元列。
        *   **依此类推**：从最高优先级开始，逐级向下检查检验数行来确定换入变量。
    2.  **确定换出变量**：这一步与标准单纯形法**完全相同**。使用**最小比值法则**确定主元行。
    3.  **迭代更新**：与标准单纯形法**完全相同**，进行高斯消元。
*   **最优判据**：当从 `P₁` 到 `Pₖ` 的所有检验数行都**非负**时，算法达到最优（满意解）。

> **关键点**：在选择换入变量时，**高优先级具有绝对的“否决权”**。只要高优先级的目标还有优化的空间（检验数有负值），就轮不到低优先级来决定方向。
