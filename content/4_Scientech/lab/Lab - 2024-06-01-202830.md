## 实验一：眼科病床优化问题

### 问题描述

我们考虑某医院眼科病床的合理安排的数学建模问题。

该医院眼科门诊每天开放，住院部共有病床79张。该医院眼科手术主要分三大类：白内障、外伤和其它疾病。data.xlsx中给出了2008年7月13日至2008年9月11日这段时间里各类病人的情况。

白内障手术较简单，而且没有急症。目前该院是每周一、三做白内障手术，此类病人的术前准备时间只需1、2天。做两只眼的病人比做一只眼的要多一些，大约占到60%。如果要做双眼是周一先做一只，周三再做另一只。

外伤疾病通常属于急症，病床有空时立即安排住院，住院后第二天便会安排手术。

请完成以下任务：将病人按以上三类进行分组，每类病人占用 $C_{i}$ 个病床，建立三个平行的排队论系统 M/M/ $C_{i}$，然后根据历史数据求出最优值

### 问题解决

1.  数学建模：利用 M/M/c 排队论模型，将问题建模为：

$$
\begin{align}
& \sum_{i=1}^3\hat{\alpha}_iW_i \\
s.t. &\sum_{i=1}^{3}C_i=79 \\
&C_i\geq\frac{\hat{\lambda}_i}{\hat{\mu}_i},C_i\in\mathbb{Z}^+,i=1,2,3
\end{align}
$$

其中 $W_i,\hat{\alpha}_i,\hat{\lambda}_i,\hat{\mu}_i$ 分别为第 $i$ 组队列的平均逗留时间，病人占总人数的平均比例，平均到达率和单位时间内被服务的个数。

2.  确定建模中各参数的估计值，由于对于相互独立的服从指数分布 $Exp(\lambda)$ 的样本，其极大似然估计和矩估计量均为 $\frac{n}{\sum_{i=1}^{n}X_{i}}$

利用 data. xlsx 历史数据，先将比例按类型分成三类。在每类中，$\frac{n_{i}-1}{T_{n_{i}}-T_{1}}$ 作为 $\lambda_{i}$ 的估计量，其中 $T_{n_{i}},T_{1}$ 表示最晚和最早的入院时间；对于每个病人，计算住院时长 $X_{j}$，将 $\frac{1}{\overline{X}}$ 作为 $\mu_{i}$ 的估计量。将 $\frac{n_{i}}{n_{1}+n_{2}+n_{3}}$ 作为 $\alpha_{i}$ 的估计量。

3.  利用 $$p_0=\left[\sum\limits_{n=0}^{s-1}\frac{\rho^n}{n!}+\frac{\rho^s}{s!(1-\rho / s)}\right]^{-1}$$

其中 $\rho = \frac{\lambda}{\mu}$

$$
\begin{align}
L_{\mathrm{q}}&=\sum_{n=s+1}^{\infty}\left(n-s\right)p_{n}=\frac{p_{0}\rho^{s}}{s!}\sum_{n=s}^{\infty}\left(n-s\right) (\frac{\rho}{s})^{n-s}\\ 
&=\frac{\frac{p_{0}\rho^{s}\rho}{s}}{s!\left(1-\frac{\rho}{s}\right)^{2}}
\end{align}
$$

再利用 $W_{s} = \frac{L_{q}}{\lambda} + \frac{1}{\mu}$，就可以得到每个 $C_{i} = s$ 下的平均等待时长的公式。

4.  遍历满足条件的整数 $(C_{1},C_{2},C_{3})$，分别计算目标值 $\sum_{i=1}^{3} \hat{\alpha_{i}}W_{i}$，记录最小值，找到对应的病床分配方案 $(C_{1},C_{2},C_{3})$

### 代码

``` matlab
lambdas = zeros(1,3); % 达到速率

mus = zeros(1,3); % 服务速率

alphas = [154, 55, 140]; % 人数占比

lambdas(1,1) = (alphas(1,1)-1)/44;

lambdas(1,2) = (alphas(1,2)-1)/53;

lambdas(1,3) = (alphas(1,3)-1)/37;

mus(1,1) = (alphas(1,1))/1079;

mus(1,2) = (alphas(1,2))/387;

mus(1,3) = alphas(1,3)/1676;

mintime = 1000000;

for c1 = 0:79

for c3 = 0:(79-c1-c2)

if c1>lambdas(1,1)/mus(1,1) && c2>lambdas(1,2)/mus(1,2) && c3>lambdas(1,3)/mus(1,3)

time = alphas(1,1)*find_wn(lambdas(1,1), mus(1,1), c1)+ alphas(1,2)*find_wn(lambdas(1,2), mus(1,2), c2) + alphas(1,3)*find_wn(lambdas(1,3), mus(1,3), c3);

if time<mintime

mintime = time;

end

end

end

end

end

disp(['result=', num2str(mintime)]);

disp(['最佳床位分配：', num2str(minc)]);

function Wn = find_wn(lambda, mu, c)

p0 = 0;

for k=0:c-1

p0 = p0 + power(lambda/mu,k)/factorial(k);

end

p0 = p0 + power(lambda/mu, c)/factorial(c)/(1-lambda/c/mu);

p0 = 1/p0;

Lq = p0* power(lambda/mu, c)*(lambda/c/mu)/factorial(c)/(1-lambda/c/mu)/(1-lambda/c/mu);

Ls = Lq + lambda/mu;

Wn = Ls/lambda;

end
```

## 实验二：排队模拟仿真

### 问题描述

请应用仿真方法，求出教材P366上例3的平均队长及平均队列长。

![](排队论实验2%201.bmp)

### 问题解决

1.  建立 M/M/1 排队论模型，根据数据计算 $\lambda$ 和 $\mu$ 的估计值。
2.  设置顾客个体，按 $Exp(\lambda)$ 和 $Exp(\mu)$ 分布随机生成每个顾客的达到时间间隔和服务时间
3.  迭代计算，标记每个顾客的达到时间，离开时间，等待时间，逗留时间
4.  以整数时刻为节点，计算每个时刻系统内的人数和排队人数。
5.  计算平均队长、平均系统内人数以及平均等待时间，平均逗留时间。

### 代码

``` matlab
lambda = 0*10 + 1*28 +2*29 + 3*16 + 4*10 +5*6 +6*1;

lambda = lambda/100;

lambda

mu = 0.1*38+ 0.3*25 + 0.5*17 + 0.7*9 + 0.9*6+ 1.1*5 + 1.3*0;

mu = 100/mu;

mu

% M/M/1 排队模型仿真

T0 = 1;

queue = []; % 队长

queue0 = []; % 队列长

arrival_times = cumsum(exprnd(1/lambda,1,200)); % 到达间隔

departure_times = exprnd(1/mu, 1, 200); % 服务时间

serve_times = zeros(1,200); % 服务时刻

leave_times = zeros(1,200); % 离开时刻

wait_times = zeros(1,200); % 等待时长

serve_times(1,1) = arrival_times(1,1);

leave_times(1,1) = arrival_times(1,1)+departure_times(1,1);

for i = 2: 200

serve_times(1,i) = max(arrival_times(1,i),leave_times(1,i-1));

leave_times(1,i) = serve_times(1,i)+departure_times(1,i);

wait_times(1,i) = max(leave_times(1,i-1)-arrival_times(1,i),0);

end

disp(['平均等待时长:', num2str(mean(wait_times))]);

stay_times = wait_times+departure_times;

disp(['平均逗留时长：', num2str(mean(stay_times))]);

for T= 1: floor(leave_times(1,200))-1

n1 = 0;

n2 = 0;

for i =1:200

if arrival_times(1,i)<=T && arrival_times(1,i+1)>T

n1 = i;

end

if leave_times(1,i)<= T && leave_times(1,i+1)>T

n2 = i;

end

end

queue = [queue, n1-n2];

queue0 = [queue0, max(n1-n2-1,0)];

end

disp(['平均排队长：',num2str(mean(queue0))]);

disp(['系统内平均人数：', num2str(mean(queue))]);

% 绘制排队长度随时间变化的曲线

plot(1:200, serve_times);

hold on;

plot(1:200, leave_times);

hold on;

plot(1:200, wait_times);

hold on;

plot(1:200, stay_times);

xlabel('顾客');

ylabel('时长');

title('M/M/1 排队模型仿真');

hold off;
```
