## 实验一：最短路问题

### 问题描述

文件中给出 10 个无向连通图，存储形式为名称-点集-边集，边集表示为 (起点，终点，权值)。

任务一：使用 Dijkstra 算法求出每个图中从节点 0 到节点 4 的最短路径。

任务二：对每张图的每对起点-终点，寻找最大权值最小的路径，并输出对应的最大权值，输出为矩阵的形式。

### 问题解决

1. 数据录入，输入为无向图 graph 形式，将 nodes 和 edges 作为结构体的属性。
2. 对每张图，将原始数据转换为邻接矩阵，没有边相连的两点权值补充为 inf.
3. 使用 Dijkstra 算法，从节点 0 开始，不断将节点纳入到 S 集，并用 temp 标记最新被纳入到 S 集的节点，用 $\min\{ d(i), d(temp)+edge(temp, i)\}$ 更新最短距离，其中 d 表示目前节点 0 到每个点的最短距离。并记录每条最短路径。
4. 当 S=nodes 时，输出 d (0, 4)，并输出对应最短路径。
5. 使用 floyd 算法，对每个 i, j, k，若 $edge (i, j)>\max\{edge(i,k)+edge(k,j)\}$，则用 $\max\{edge(i,k)+edge(k,j)\}$ 代替 $edge(i,j)$，重复操作。
6. 输出结果。

	index2=ones(1,length(A(:,1))); % 存放点前一顶点的序号
	d = inf(1,length(A(:,1)));
	d(1)=0; % 存放由 1 到第i点最短通路的值

		tb=find(pb==0); % 还没有存入S的点

		tmpb=find(d(tb)==min(d(tb)));
		temp=tb(tmpb(1)); % 变换当前位置
		pb(temp)=1; % 存入S
		index1=[index1,temp]; % 存放存S集合的顺序
		temp2=find(d(index1)==d(temp)-A(temp,index1));
		index2(temp)=index1(temp2(1)); % 记录标号索引
	end

	path = 5;
	temp = 5;
	while temp ~= 1
		path = [index2(temp), path];
		temp = index2(temp);
	end

	disp(['Shortest path from node 0 to node 4:[', num2str(path-1), '],', num2str(d(1,5))]);

	% 最大权值最小路
	a = A;
	for k=1:length(a(:,1))
		for i=1:length(a(:,1))
			for j=1:length(a(:,1))
				if a(i,j)> max(a(i,k), a(k,j))
					a(i,j)=max(a(i,k), a(k,j));
				end
			end
		end
	end
	disp(a);
end

## 实验二：最大流问题

### 问题描述

对习题 11.13，11.14 两个问题，求解出对应的最大流，并给出对应的最小割。

### 问题解决

1. 录入数据
2. 将数据转化为有向图 digraph 格式，如果多起点终点则补充虚拟起点终点 s, t。
3. 利用 maxflow () 函数求解最大流问题。
4. 输出最大流时对应的流量矩阵和最大流量。
5. 给出对应最小割。
