## 实验一：价格有折扣的存储问题

### 问题描述

给出价格有折扣的存储问题的程序实现，考虑生产速度有限，容许缺货的一般情形。输入参数为：需求速度 $R$, $C_1,C_2$, $C_3$, 生产速度 $P$, 以及价格向量 $(K_1,K_2,\ldots,K_m)$ 及"价格转折点"向量$(Q_{1},Q_{2},\ldots,Q_{m-1})$。输出参数为：最佳订货量 $Q^*$, 最大库存量，最大缺货量，单位货物的平均费用(存储费，缺货费，订购费，价格).

### 问题解决

1. 先求出没有折扣时的极小值点 
$$
Q_{0} = \sqrt{ \frac{2C_{3}R(C_{1}+C_{2})}{C_{1}C_{2}} \cdot \frac{P}{P-R} }
$$

2. 对区间 $(Q_{i-1}, Q_{i}],i=1,2,\dots$，其中 $Q_{0} =0, Q_{m} =+\infty$，如果 $Q_{0}\in (Q_{i-1},Q_{i}]$，则在此区间中的最佳值为 $C(K_{i},Q_{0})$，如果 $Q_{0}>Q_{i}$，则此区间中的最佳值为 $C(K_{i}, Q_{i})$，如果 $Q_{0}<Q_{i-1}$，则此区间内的最佳值为 $C(K_{i}, Q_{i-1})$。其中
$$
C(K,Q) = \frac{1}{2} \cdot \frac{C_{1}C_{2}}{C_{1}+C_{2}} \cdot \frac{P-R}{P}Q  + \frac{C_{3}R}{Q} +RK
$$

3. 将每个区间的最佳值进行比较，取最小的成本以及对应的采购量作为最佳采购量 $Q^{*}$ 和最优成本 $C^{*}$。再利用
$$
\begin{align}
S^{*}= \frac{C_{2}}{C_{1}+C_{2}} \cdot \frac{{P-R}}{P} Q^{*} \\
B^{*} = \frac{C_{1}}{C_{1}+C_{2}} \cdot \frac{{P-R}}{P} Q^{*}
\end{align}
$$
求出对应法最大库存量和最大缺货量。

### 代码


```MATLAB
R= input("R=");

C1 = input("C1=");

C2 = input("C2=");

C3 = input("C3=");

P = input("P=");

m = input("价格分段数为：");

K = zeros(1,m);

Q = zeros(1,m-1);

K= input("K=");

Q = input("Q=");

Q=[0,Q];

Qbest = zeros(1,m);

Q0 = sqrt(2*C3*R/C1*(C1+C2)/C2*P/(P-R));

Cost = zeros(1,m);

for i=1:m-1

if Q0 <= Q(1,i)

Cost(1,i) = cost(R, C1, C2, C3, P, K(1,i), Q(1,i));

Qbest(1,i) = Q(1,i);

elseif Q0 > Q(1,i) && Q0 <= Q(1,i+1)

Cost(1,i) = cost(R, C1, C2, C3, P, K(1,i), Q0);

Qbest(1,i) = Q0;

elseif Q0> Q(1,i+1)

Cost(1,i) = cost(R,C1,C2,C3,P,K(1,i),Q(1,i+1));

Qbest(1,i) = Q(1,i+1);

end

end

if Q0>Q(1,m)

Cost(1,m) = cost(R,C1,C2,C3,P,K(1,m),Q0);

Qbest(1,m) = Q0;

else

Cost(1,m) = cost(R,C1,C2,C3,P,K(1,m),Q(1,m));

Qbest(1,m) = Q(1,m);

end

minvalue = min(Cost);

j = find(Cost == minvalue,1);

bestQ = Qbest(1,j);

mincost = Cost(1,j);

S = bestQ*C2/(C1+C2)*(P-R)/P;

B = bestQ*C1/(C1+C2)*(P-R)/P;

disp(['最佳订货量为',num2str(bestQ)]);

disp(['最大库存量为',num2str(S)]);

disp(['最大缺货量为',num2str(B)]);

disp(['平均费用为',num2str(mincost)]);

function C = cost(R, C1, C2, C3, P, K, Q)

C = 1/2*C1*C2*C2/(C1+C2)/(C1+C2)*Q*(P-R)/P + 1/2*C2*C1*C1/(C1+C2)/(C1+C2)*Q*(P-R)/P + C3*R/Q + R*K;

end
```



## 实验二：(s, S) 存储策略求解

### 问题描述

给出在需求为连续和离散随机变量情况下，(s, S) 存储策略的求解程序。

### 问题求解

1. 首先将连续分布转换为离散分布，具体为取一些代表点 $Q_{1}, Q_{2},\dots,Q_{n}$，利用 $P (X= Q_{i})=\int _{Q_{i-1}}^{Q_{i}}  f (x) \, dx ,i=1,2,\dots,n-1$ 化为取值为 $Q_{1},Q_{2},\dots,Q_{n}$ 的离散分布，其中 $Q_{0} =0,P(X=Q_{n})=\int _{Q_{n-1}}^{+\infty} f(x)\, dx$
2. 首先找到 $\sum_{j=1}^{i-1} P_{j}< \frac {{C_{2}-K}} {C_{1}+C_{2}}\leq \sum_{j=1}^{i}P_{j}$，并将 $Q_{i}$ 作为 S 的值
3. 在 $(0,S]$ 中以较小步长搜索满足条件的 s, 对每个 s 计算成本 C（s），如果 $C(s)<C(S)+C_{3}$，其中 $C_{3}$ 为单次进货价，则 s 是符合条件的，取最小的满足条件的 s 作为下界 s。

当 $I\geq s$ 时，不补货；当 $I<s$ 时补货 $Q=S-I$

### 代码


```MATLAB
Q = [60,80,100,120];

p = [0.2, 0.2, 0.4, 0.2];

k = 1600;

C1 = 80;

C2 = 2100;

K0 = 300;

[s,S] = solveSSStoragePolicy(Q, p, C1, C2, k, K0);

disp([s,S]);

function [s, S] = solveSSStoragePolicy(Q, p, C1, C2, k, K0)

% 初始化一些变量

minCost = inf;

bestS = 0;

if p(1,1) >= (C2-k)/(C1+C2)

bestS = Q(1,1);

end

for i=2:length(Q)

if (C2-k)/(C1+C2)<=sum(p(1:i)) && (C2-k)/(C1+C2)>sum(p(1:i-1))

bestS = Q(1,i);

end

end

minCost = calculateCost(Q, p, C1, C2, k, bestS);

bests = bestS;

for s = 0: floor(bestS)

cost = calculateCost(Q, p, C1, C2, k, s);

if cost < minCost + K0

bests = min(s,bests);

end

end

s = bests;

S = bestS;

end

function cost = calculateCost(Q, p, C1, C2, k, S)

% 计算成本的具体逻辑

l = length(Q);

expectedOverstock = 0;

expectedUnderstock = 0;

for i=1:l

expectedOverstock = expectedOverstock + max(0, S - Q(1,i))* p(1,i);

expectedUnderstock = expectedUnderstock + max(0, Q(1,i) - S)*p(1,i);

end

cost = C1 * expectedOverstock + C2 * expectedUnderstock + k* S;

end
```

### 输出结果

以书上例 9 为例子，最终结果为 S=80，s=76。与 PPT 上的结果基本一致。 

## 实验三：协调决策模型

### 问题描述

给出基于退货价格契约的两级供应链订货量协调决策模型的求解程序。

### 问题求解

1. 同实验二，要先将连续需求随机变量分布化为离散分布统一处理。
2. 利用公式 
$$
S = \frac{P(W-C_{S})}{P-C_{I}-C_{S}}
$$

求出协调价格。
3. 寻找 $\sum_{j=1}^{i-1}P_{j}< \frac {{P-C_{I}-C_{S}} }{P} \leq \sum_{j=1}^{i}P_{j}$，将 $Q_{i}$ 作为最佳的订购量 $Q^{*}$。

### 代码


```MATLAB
P =80;

CI =10;

Cs = 50;

W = 60;

% 正态分布参数

mu = 100; % 均值

sigma = 20; % 标准差

numBins = 40; % 分割成的区间数量

% 创建离散区间

intervalEdges = linspace(mu - 3*sigma, mu + 3*sigma, numBins+1); % 考虑正负3sigma范围

Q = (intervalEdges(1:end-1) + intervalEdges(2:end))/2; % 区间中点

Prod = normcdf(intervalEdges(2:end), mu, sigma) - normcdf(intervalEdges(1:end-1), mu, sigma); % 各区间概率

Prod = Prod / sum(Prod);

% 打印结果

disp('Discrete Values (Q)');

disp(Q);

disp('Probabilities (Prod)');

disp(Prod);

[S,Q0] = bestcooperation(Q, Prod, CI, Cs, W, P)

function [S,Q0] = bestcooperation(Q, prob, CI, Cs, W, P)

S = P*(W-Cs)/(P-CI-Cs);

if prob(1,1) >= (P-CI-Cs)/P

Q0 = Q(1,1);

end

for i =2:length(Q)

if (P-CI-Cs)/P>sum(prob(1:i-1)) && (P-CI-Cs)/P<=sum(prod(1:i))

Q0 = Q(1,i);

end

end

end
```

### 输出结果

对于连续分布 $N(100,20^{2})$，将其进行离散化处理，在 $[\mu-3\sigma,\mu+3\sigma]$ 区间内将区间均分为 40 份作为离散分布的取值点，计算每个离散点的等价概率密度。

最终结果为 $S = 40,Q^{*}=86.5$，与 PPT 上的结果基本一致。

## 实验四：供应链协调模型

### 问题描述

给出基于收益分享契约的两阶段供应链协调模型的求解程序。

### 问题求解

1. 首先同实验二和实验三，先将连续分布转化为离散分布统一处理。
2. 对供应链来说，寻找 $\sum_{j=1}^{i-1}P_{j}< \frac {{P-C_{S}-C_{T}-C_{I}} }{P}< \sum_{j=1}^{i}P_{j}$，将 $Q_{i}$ 作为供应链的最佳订货量 $q_{T}$，并求出对应的利润 $\Pi_{T}$
3. 对零售商来说，寻找 $\sum_{j=1}^{i-1}P_{j}< \frac {{P-\omega_{0}-C_{T}-C_{I}} }{P}< \sum_{j=1}^{i}P_{j}$，将 $Q_{i}$ 作为零售商的最佳订货量 $q_{I}$，并求出对应利润 $\Pi_{I}$.
4. 对应的供应商合作前的利润为 $\Pi_{S} = (\omega_{0}-C_{S})q_{I}$
5. 利用公式
$$\max\left\{\frac{C_I+C_T}{C_I+C_S+C_T},\frac{E(\Pi_{I}^*)}{E(\Pi_T^*)}\right\}\leq\phi\leq1-\frac{E(\Pi_{S}^*)}{E(\Pi_T^*)}$$
求出 $\phi$ 的取值范围，对应的 $\omega = \phi(C_{I}+C_{S}+C_{T})-C_{I}-C_{T}$

### 代码


```MATLAB
CI =10;

CS = 28;

CT = 8;

w0 = 45;

P = 80;

% 正态分布参数

mu = 110; % 均值

sigma = 20; % 标准差

numBins = 40; % 分割成的区间数量

% 创建离散区间

intervalEdges = linspace(mu - 3*sigma, mu + 3*sigma, numBins+1); % 考虑正负3sigma范围

Q = (intervalEdges(1:end-1) + intervalEdges(2:end))/2; % 区间中点

Prod = normcdf(intervalEdges(2:end), mu, sigma) - normcdf(intervalEdges(1:end-1), mu, sigma); % 各区间概率

Prod = Prod / sum(Prod);

[minphi,maxphi] = bestcooperation(Q, Prod, CI, CT,CS, P, w0)

function [minphi, maxphi] = bestcooperation(Q, prob, CI, CT, CS, P, w)

qT = 0;

if prob(1,1) >= (P-CI-CS-CT)/P

qT = Q(1,1);

end

for i =2:length(Q)

if (P-CI-CS-CT)/P>sum(prob(1:i-1)) && (P-CI-CS-CT)/P<=sum(prob(1:i))

qT = Q(1,i);

end

end

costT = calculateCost(Q, prob, 0, P, CI+CT+CS, qT);

qI = 0;

if prob(1,1) >= (P-CI-w-CT)/P

qI = Q(1,1);

end

for i =2:length(Q)

if (P-CI-w-CT)/P>sum(prob(1:i-1)) && (P-CI-w-CT)/P<=sum(prob(1:i))

qI = Q(1,i);

end

end

costI = calculateCost(Q, prob, 0, P, CI+CT+w, qI);

costS = (w-CS)*qI;

minphi = max((CI+CT)/(CI+CT+CS),costI/costT);

maxphi = 1- costS/costT;

end

function cost = calculateCost(Q, p, C1, C2, k, S)

% 计算成本的具体逻辑

l = length(Q);

expectedOverstock = 0;

expectedUnderstock = 0;

for i=1:l

expectedUnderstock = expectedUnderstock + min(S, Q(1,i))*p(1,i);

end

cost = C1 * expectedOverstock + C2 * expectedUnderstock - k*S;

end
```

### 输出结果

以课件上的分布 $X\sim N(110,20^{2})$ 为例子，先离散化分布函数，利用程序求解结果为 $\phi  \in[0.4524,0.4903]$

与 PPT 上的结果基本一致
