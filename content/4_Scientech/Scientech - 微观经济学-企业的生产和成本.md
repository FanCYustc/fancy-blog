# 第三章-企业的生产和成本

[[Scientech - 微观经济学-消费者选择]]

| 消费者                                                           | 生产者                                                           |
| ------------------------------------------------------------- | ------------------------------------------------------------- |
| $商品x_{1},\dots x_{n}\to 效用u$                                  | $生产要素v_{1},\dots,v_{n}\to产量Q$                                 |
| 效用函数                                                          | 生产函数                                                          |
| 效用最大化：$\max u(x_{1},\dots x_{n})$ s.t. $\sum p_{i}x_{i}=m$    | 生产函数：$\max Q(v_{1},\dots v_{n})$ s.t. $\sum w_{i}v_{i}=C$     |
| 消费最小：$\min \sum p_{i}x_{i}$ s.t. $u(x_{1},\dots x_{n})=u_{0}$ | 成本函数：$\min \sum w_{i}v_{i}$ s.t. $Q(v_{1},\dots v_{n})=Q_{0}$ |
| 预算约束线                                                         | 成本约束线                                                         |
| 无差异曲线                                                         | 生产要素的替代关系                                                     |
| 收入拓展线                                                         | 成本拓展线                                                         |
